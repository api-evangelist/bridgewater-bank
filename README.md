# Bridgewater Bank (bridgewater-bank)

Bridgewater Bank is a Canadian Schedule I chartered bank, a wholly-owned subsidiary of the Alberta Motor Association (AMA), headquartered in Calgary, Alberta and established in 1997. A member of the Canada Deposit Insurance Corporation (CDIC), it runs a broker-distributed deposit-and-lending model — residential mortgages, GICs, and high-interest savings accounts — with roughly $3.3 billion in mortgages and deposits across approximately 53,000 customer accounts nationwide.

## Open-Finance / API Posture

Bridgewater Bank exposes **no public first-party developer API and no developer portal**. There is no `developer.bridgewaterbank.ca` and no `api.bridgewaterbank.ca` developer surface, and no downloadable OpenAPI/Swagger specification is published. The only dedicated digital surface beyond the corporate site is a partner-gated broker information portal (bwbbrokerinfo.ca).

Canada's federal Consumer-Driven Banking (open-banking) framework — legislated under Budget 2024 and the Fall Economic Statement 2024, with the Financial Consumer Agency of Canada (FCAC) as overseer — is legislated but **not yet operational**. Access to Canadian consumer banking data today is voluntary and fragmented; for an institution of this size and model, any consumer data access would be aggregator/screen-scraping based (e.g. Flinks, Plaid, MX, Salt Edge) rather than through a documented first-party API. Bridgewater Bank publicly documents no Interac, Real-Time Rail (RTR), FDX, or consumer-driven-banking API participation.
